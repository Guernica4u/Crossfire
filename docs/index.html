The public pool A shared shelf of free-tier keys

Keep the room open.

The free tier runs out. Crossfire accepts contributed free-tier OpenRouter keys and uses them only after the owner key is unavailable. The key is verified, encrypted at rest, and never shown back in the interface.

Read the pool contract ↗
01 Owner first

The local key is always tried before a community key.

02 Free models only

Paid keys are rejected. The app has no paid fallback path.

03 Server-side

The pool needs the Node app. GitHub Pages cannot accept keys.

Hosting note. This GitHub Pages site is the front door. The arena, the SQLite archive, the stream, and the public key pool run on a Node server — either your machine or a host you control.
How it works A debate, not a chatbot
01

Set the table

Pick a question. Give each of three models a position: for, against, or undecided.

02

Let them clash

Openings, rebuttals, and closings stream one voice at a time. You can cut in.

03

Hear the bench

The judge scores the exchange, names what survived, and records the verdict.

Run it

The arena is local.

Crossfire needs Node 24 or newer and a free OpenRouter key. The Control Panel finds or saves the key, starts the server, and opens the room.

Open the setup guide 
$ git clone https://github.com/Guernica4u/crossfire-arena.git
$ cd crossfire-arena
$ npm install
$ npm run go
